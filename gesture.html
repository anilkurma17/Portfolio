Real-Time Gesture Recognition System

A system for real-time hand gesture recognition to control appliances, integrating computer vision and hardware automation.

Project Contribution

Role: Developer

Description: Built a real-time gesture recognition system using MediaPipe and OpenCV to control appliances. Integrated GPIO scripts for hardware automation on Raspberry Pi. Implemented gesture classification using landmark-based angle measurement. Designed a simple GUI to indicate recognized gestures and device states.

Problem: Manual control of appliances can be inconvenient or inaccessible for some users. Gesture-based control offers a touchless, intuitive solution.

My Approach: I developed a system using the following technologies:

  • Python for core logic and hardware integration
  • MediaPipe & OpenCV for gesture recognition
  • Raspberry Pi GPIO for device control
  • tkinter for GUI

Final Result: Enabled seamless, real-time gesture-based control of appliances, improving accessibility and user experience.
